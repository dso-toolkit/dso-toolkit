# Icon Button

Icon Buttons zijn knoppen die uitsluitend bestaan uit een icoon. Ze worden ingezet wanneer er onvoldoende ruimte is voor een button met tekst, bijvoorbeeld in een tabel met veel acties of op een kaart. Omdat een Icon Button geen zichtbaar tekstlabel heeft, is toegankelijkheid extra belangrijk. Elke Icon Button heeft daarom een toegankelijke naam via `label`. Een `tooltip` is optioneel.

- Het `label` wordt voorgelezen door screenreaders en is de toegankelijke naam.
- De `tooltip` toont standaard het `label` en wordt zichtbaar bij hover of focus.

Het advies blijft om zoveel mogelijk het component Button ("reguliere" button met label) te gebruiken, omdat deze voor alle gebruikers duidelijker is. De Icon Button is bedoeld voor uitzonderingssituaties waar een label niet past, maar een compacte actieknop nodig is.

**Belangrijke aandachtspunten:**

- Icon Buttons hebben altijd een toegankelijke naam, ingesteld met `label`.
- De tooltip toont standaard het `label`. Met `tooltip` kan een kortere tekst worden ingesteld.
- Er zijn drie varianten beschikbaar: Secondary, Tertiary en Map.
- De Icon Button lijkt visueel sterk op de standaard Button en is WCAG-compliant.

## Korte tooltip met context

Met `tooltip` kan een kortere tekst in de tooltip worden getoond, terwijl `label` de voorgelezen tekst is. Gebruik dit wanneer de context naast de knop zichtbaar is, maar een schermlezergebruiker die context anders mist, zoals bij een lijst met gelijke knoppen.

De tekst van `tooltip` moet als losse woorden, gescheiden door spaties, in `label` voorkomen, bij voorkeur vooraan. Is dit niet het geval, dan geeft het component een waarschuwing in de console.
