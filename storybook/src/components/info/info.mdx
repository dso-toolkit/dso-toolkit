# Info

<Canvas of={Stories.Default} />

Afbeeldingen worden in <code>form dso-info</code> in het midden uitgelijnd

## Label van de sluitknop

De sluitknop heeft standaard het label "Sluiten". Maak het label met `closeLabel` specifiek voor de context, bijvoorbeeld "Sluit toelichting" gevolgd door het label van de vraag of optie.

## Focus

Sluit de gebruiker de Info met de sluitknop, dan verdwijnt de sluitknop en is de focus weg. De afnemer zet de focus terug, meestal op de Info Button die de Info opende.

Wordt de Info actief, dan onthoudt de Info het element dat op dat moment focus had. Dat element zit als `previousActiveElement` in het `dsoClose`-event:

```typescript
info.addEventListener("dsoClose", (e: DsoInfoCustomEvent<InfoCloseEvent>) => {
  info.active = false;

  e.detail.previousActiveElement?.focus();
});
```

Is de Info op een andere manier geopend dan met de Info Button, gebruik dan `setFocus()` op `<dso-info-button>`.
