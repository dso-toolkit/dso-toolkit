# React bindings

De toolkit levert gegenereerde React-wrappers voor de Web Components. Gebruik deze bindings in een React-applicatie. De bindings geven props door aan het onderliggende Web Component en maken events beschikbaar als React event handlers.

## Met React bindings

Installeer de React bindings naast de basis package:

```sh
npm install @dso-toolkit/react
```

Laad daarnaast de stylesheet `dso-toolkit/dist/dso.css`. De bindings registreren de componenten zelf.

Importeer de gegenereerde `Dso*`-componenten. Je zet props als JSX-props en luistert naar custom events met een `onDso...`-prop.

```tsx
import { useState } from "react";

import { DsoDatePicker } from "@dso-toolkit/react";

export function App() {
  const [date, setDate] = useState("");

  return <DsoDatePicker value={date} onDsoDateChange={(event) => setDate(event.detail.value)} />;
}
```

Gebruik `<DsoDatePicker>` en niet rechtstreeks `<dso-date-picker>`. Voor een event met de naam `dsoChange` is de React-prop `onDsoChange`; `dsoSelect` en `dsoSearch` worden respectievelijk `onDsoSelect` en `onDsoSearch`. Bij Autosuggest ziet dat er bijvoorbeeld zo uit: `<DsoAutosuggest onDsoChange={handleChange} onDsoSelect={handleSelect} onDsoSearch={handleSearch} />`.

## Zonder React bindings

Zonder bindings gebruik je de Web Components rechtstreeks. Installeer en registreer ze zoals beschreven op [Web Components](?path=/docs/voor-developers-web-components--docs), voordat React ze rendert.

Vanaf React 19 zet je properties en events direct op het element. React zet een prop als property op het element en maakt van een prop die met `on` begint een event listener. De eventnaam is de rest van de prop, met dezelfde hoofdletters: voor `dsoDateChange` is de prop `ondsoDateChange`.

```tsx
export function App() {
  return <dso-date-picker value="01-01-2024" ondsoDateChange={(event: CustomEvent) => console.log(event.detail)} />;
}
```

Bij React 18 zet je properties op het DOM-element en luister je naar custom events met `addEventListener`.

```tsx
import { useEffect, useRef } from "react";

export function App() {
  const datePicker = useRef<HTMLElement>(null);

  useEffect(() => {
    const element = datePicker.current;
    if (!element) return;

    const onDateChange = (event: Event) => console.log((event as CustomEvent).detail);
    element.addEventListener("dsoDateChange", onDateChange);

    return () => element.removeEventListener("dsoDateChange", onDateChange);
  }, []);

  return <dso-date-picker ref={datePicker} value={"01-01-2024"} />;
}
```

Zie ook de [Stencil-documentatie voor React](https://stenciljs.com/docs/react#usage).
