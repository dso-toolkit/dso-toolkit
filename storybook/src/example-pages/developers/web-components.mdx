# Web Components

De Web Components zitten in de package `dso-toolkit`. Gebruik je React of Angular, kies dan de [React bindings](?path=/docs/voor-developers-react-bindings--docs) of de [Angular bindings](?path=/docs/voor-developers-angular-bindings--docs). Die registreren de componenten voor je. Zonder bindings registreer je de componenten zelf, op een van de manieren hieronder.

```sh
npm install dso-toolkit
```

Laad in alle gevallen ook de stylesheet `dso-toolkit/dist/dso.css`.

## Per component registreren

Je registreert alleen de componenten die je gebruikt. Je bundle bevat dan alleen die componenten. Dit raden we aan voor productie.

```ts
import "dso-toolkit/dist/dso.css";
import { defineCustomElementDsoBadge, defineCustomElementDsoToggletip } from "dso-toolkit";

defineCustomElementDsoBadge();
defineCustomElementDsoToggletip();
```

Daarna werken `<dso-badge>` en `<dso-toggletip>` overal in je applicatie.

## Alle componenten met de loader

De loader registreert alle componenten in één keer. De code van een component laadt pas als je pagina het component gebruikt. Je bundle bevat wel alle componenten. Dit past bij prototypes.

```ts
import "dso-toolkit/dist/dso.css";
import { defineCustomElements } from "dso-toolkit/loader";

defineCustomElements();
```

## Via de CDN

Zonder bundler laad je de stylesheet en de loader van `cdn.dso-toolkit.nl`.

```html
<link rel="stylesheet" href="https://cdn.dso-toolkit.nl/dso-toolkit/<versie>/dist/dso.css" />
<script
  type="module"
  src="https://cdn.dso-toolkit.nl/dso-toolkit/<versie>/dist/dso-toolkit/dso-toolkit.esm.js"
></script>
```

Vul voor `<versie>` een release in, bijvoorbeeld `103.0.0`.
