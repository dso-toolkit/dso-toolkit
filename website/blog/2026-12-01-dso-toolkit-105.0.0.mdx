# DSO Toolkit v105.0.0 🐣

Deze release bevat **breaking** changes voor de volgende componenten:

- Highlight Box
- List

<!-- truncate -->

## Highlight Box

**Breaking:** De variant `With Banner Image` heet voortaan `With Image`. De afbeelding wordt via het named slot
`image` geplaatst. De class `dso-highlight-box-banner` vervalt.

### Migratiepad

```html
❌
<dso-highlight-box>
  <img src="..." class="dso-highlight-box-banner" alt="..." />
  <div class="dso-rich-content">...</div>
</dso-highlight-box>

✅
<dso-highlight-box>
  <img src="..." slot="image" alt="..." />
  <div class="dso-rich-content">...</div>
</dso-highlight-box>
```

## List

**Breaking:** De selector `ol.dso-list-ordered-action` in het HTML/CSS-component `List` is verwijderd. Deze was
deprecated sinds [v100.3.0](./2026-08-31-dso-toolkit-100.3.0.mdx).

### Migratiepad

Gebruik de `ol.dso-action-list` selector van de `List`.

```html
❌
<ol class="dso-list-ordered-action">
  <li>...</li>
</ol>

✅
<ol class="dso-action-list">
  <li>...</li>
</ol>
```
