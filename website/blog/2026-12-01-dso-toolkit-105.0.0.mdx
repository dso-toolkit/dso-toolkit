# DSO Toolkit v105.0.0 🐣

Deze release bevat **breaking** changes voor de volgende componenten:

- Highlight Box
- List

Deze release bevat een **deprecation** voor het volgende component:

- Shopping Cart (HTML/CSS implementatie)

<!-- truncate -->

## Highlight Box

**Breaking:** De variant `With Banner Image` heet voortaan `With Image`. De afbeelding wordt via het named slot
`image` geplaatst. De class `dso-highlight-box-banner` vervalt.

### Migratiepad

```html
❌
<dso-highlight-box>
  <img src="..." class="dso-highlight-box-banner" alt="..." />
  <div class="dso-rich-content">...</div>
</dso-highlight-box>

✅
<dso-highlight-box>
  <img src="..." slot="image" alt="..." />
  <div class="dso-rich-content">...</div>
</dso-highlight-box>
```

## List

**Breaking:** De selector `ol.dso-list-ordered-action` in het HTML/CSS-component `List` is verwijderd. Deze was
deprecated sinds [v100.3.0](./2026-08-31-dso-toolkit-100.3.0.mdx).

### Migratiepad

Gebruik de `ol.dso-action-list` selector van de `List`.

```html
❌
<ol class="dso-list-ordered-action">
  <li>...</li>
</ol>

✅
<ol class="dso-action-list">
  <li>...</li>
</ol>
```

## Shopping Cart (HTML/CSS implementatie)

De HTML/CSS implementatie van het component `Shopping Cart` is deprecated. De alternatieve implementatie `<dso-shopping-cart>` is uitgebracht in 🪅 Release 100.2.0.

### Migratiepad

Gebruik de Web Component `<dso-shopping-cart>`.

```html
❌
<div class="dso-shopping-cart">
  <div class="dso-contents">...</div>
</div>

✅
<dso-shopping-cart mode="main|side" ...>
  <h3 slot="heading">Gekozen activiteiten</h3>
  <dso-shopping-cart-item ...> ... </dso-shopping-cart-item>
</dso-shopping-cart>
```
