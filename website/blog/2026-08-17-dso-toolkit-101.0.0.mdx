# DSO Toolkit v101.0.0 🪅

Deze release bevat een **deprecation** voor het volgende component:

- Hero Image

<!-- truncate -->

## Hero Image

De selector `dso-banner` op het van Bootstrap afgeleide 12-koloms gridsysteem is deprecated en wordt verwijderd in een toekomstige **BREAKING** release. Afnemers die `.dso-banner` momenteel
gebruiken voor bijvoorbeeld achtergrondafbeeldingen op landingspagina's, moeten overstappen naar alternatieve componenten om lay-outproblemen te voorkomen.

### Migratiepad

Vervang de oude CSS-selector door het `<dso-hero-image>` Web Component.

```html
❌
<div class="row dso-banner no-button-banner my-beautiful-image">
  <div class="col-lg-6 col-md-9 col-sm-12 col-xs-12">
    <dso-highlight-box white> ... </dso-highlight-box>
  </div>
</div>

✅
<dso-hero-image>
  <div class="my-beautiful-image" slot="image"></div>
  <dso-highlight-box white> ... </dso-highlight-box>
</dso-hero-image>
```
