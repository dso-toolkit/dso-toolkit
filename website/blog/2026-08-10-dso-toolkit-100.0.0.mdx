# DSO Toolkit v100.0.0 💯

Deze release bevat **BREAKING** changes voor de volgende componenten:

- Info (HTML/CSS implementatie)
- List

<!-- truncate -->

## Info (HTML/CSS implementatie)

De HTML/CSS implementatie van het component `Info` is in 🏴󠁧󠁢󠁳󠁣󠁴󠁿 97.0.0 **deprecated**. In deze release is deze implementatie verwijderd.

### Migratiepad

Gebruik het Core component `Info`.

```html
❌
<div class="dso-info">
  <div class="dso-rich-content">...</div>
  <button type="button" class="">
    <span class="sr-only">Sluiten</span>
  </button>
</div>

✅
<dso-info fixed="" active="">
  <div class="dso-rich-content">...</div>
</dso-info>
```

## List

De selector `ol.dso-list-ordered-action` in het HTML/CSS-component `List` is in 🧱 Release 91.0.0 **deprecated**.
In deze release is deze selector verwijderd.

### Migratiepad

Gebruik de `ol.dso-action-list` selector van de `List`.

```html
❌
<ol class="dso-list-ordered-action">
  <li>...</li>
</ol>

✅
<ol class="dso-action-list">
  <li>...</li>
</ol>
```
