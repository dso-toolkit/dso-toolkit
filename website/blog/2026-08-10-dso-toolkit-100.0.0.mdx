## Info (HTML/CSS implementatie)

De HTML/CSS implementatie van het component `Info` is in 🏴󠁧󠁢󠁳󠁣󠁴󠁿 97.0.0 **deprecated**. In deze release is deze implementatie verwijderd.

### Migratiepad

Gebruik het Core component `Info`.

```html
❌
<div class="dso-info">
  <div class="dso-rich-content">...</div>
  <button type="button" class="">
    <span class="sr-only">Sluiten</span>
  </button>
</div>

✅
<dso-info fixed="" active="">
  <div class="dso-rich-content">...</div>
</dso-info>
```
