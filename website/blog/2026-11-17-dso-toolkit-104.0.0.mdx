# DSO Toolkit v104.0.0 🔦

Deze release bevat **BREAKING** changes voor de componenten:

- Grid
- Info

Daarnaast zijn het label van de sluitknop en het focusmanagement van de toelichting bij Info en Selectable verbeterd.

<!-- truncate -->

## Grid

**Breaking:** De selectors `.dso-banner` en `.no-button-banner` in combinatie met de selector `.row` van het Grid zijn
verwijderd. Deze waren deprecated sinds [v100.2.0](./2026-08-24-dso-toolkit-100.2.0.mdx).
Afnemers die deze selectors nog gebruiken om een Highlight Box op of onder een achtergrondafbeelding op
landingspagina's te tonen, moeten overstappen naar het nieuwe webcomponent `Hero Image`.

### Migratiepad

Vervang de oude HTML markup met classes `row dso-banner no-button-banner` en de custom-class met daarin de
background-image styling door het web component `Hero Image`.

```html
❌
<div class="row dso-banner no-button-banner my-beautiful-image">
  <div class="col-lg-6 col-md-9 col-sm-12 col-xs-12">
    <dso-highlight-box white> ... </dso-highlight-box>
  </div>
</div>

✅
<dso-hero-image>
  <div class="my-beautiful-image" slot="image"></div>
  <dso-highlight-box white> ... </dso-highlight-box>
</dso-hero-image>
```

## Info

**Breaking:** Het `dsoClose` event van `dso-info` geeft niet langer een `MouseEvent` mee, maar een `InfoCloseEvent`:

```ts
interface InfoCloseEvent {
  originalEvent: MouseEvent;
  previousActiveElement?: HTMLElement;
}
```

Het oorspronkelijke klik-event staat nu in `originalEvent`. In `previousActiveElement` staat het element dat focus had
op het moment dat de Info actief werd, meestal de Info Button. Na het sluiten verdwijnt de sluitknop en daarmee de
focus. Met `previousActiveElement` kun je de focus terugzetten.

Verder heeft de Info een nieuwe property `closeLabel` (attribuut `close-label`) gekregen. Hiermee geef je de sluitknop
een specifiek label, bijvoorbeeld "Sluit toelichting". Standaard is het label "Sluiten".

### Migratiepad

Lees het klik-event uit `originalEvent` en zet na het sluiten de focus terug.

```ts
❌
info.addEventListener("dsoClose", (e: DsoInfoCustomEvent<MouseEvent>) => {
  info.active = false;

  console.log(e.detail.target);
});

✅
info.addEventListener("dsoClose", (e: DsoInfoCustomEvent<InfoCloseEvent>) => {
  info.active = false;

  console.log(e.detail.originalEvent.target);
  e.detail.previousActiveElement?.focus();
});
```

Is de Info op een andere manier geopend dan via de Info Button? Gebruik dan `setFocus()` van `dso-info-button` om de
focus terug te zetten.

```html
❌
<dso-info active>...</dso-info>

✅
<dso-info active close-label="Sluit toelichting Wenst u een toelichting op deze vraag?">...</dso-info>
```

## Selectable

De Selectable zet na het sluiten van de toelichting de focus automatisch terug op de Info Button. Hiervoor is geen
migratie nodig.

Met de nieuwe property `infoCloseLabel` (attribuut `info-close-label`) geef je de sluitknop van de toelichting een
specifiek label. Standaard is het label "Sluiten".

```html
<dso-selectable type="radio" value="ja" info-close-label="Sluit toelichting Ja">
  Ja
  <div class="dso-rich-content" slot="info">...</div>
</dso-selectable>
```
